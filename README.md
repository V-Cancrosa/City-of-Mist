# City of Mist

Materiały i dodatki do sesji City of Mist oraz moduł FoundryVTT.

**Strona projektu:** https://v-cancrosa.github.io/City-of-Mist/

Repozytorium gromadzi style, skrypty i polskie tłumaczenia wspierające kampanię w klimacie miejskiego noir, śledztw i legend przenikających codzienność.

## O projekcie

City of Mist to świat, w którym każda ulica ma swoją pamięć, każdy ślad prowadzi do ukrytego sekretu, a każde wyjście z ciemności może być początkiem nowej tragedii. To miejsce, w którym detektywistyczna groza, dramat osobisty i miejskie legendy splatają się w mroczną opowieść.

Strona GitHub Pages przedstawia projekt i jego założenia.

## Główne założenia

- moduł kompatybilny z FoundryVTT
- własne style CSS do zmiany wyglądu interfejsu
- lokalne tłumaczenia językowe
- automatyzacje JS dla kampanii i integracji
- miejsce na grafiki, dźwięki, zasoby i dodatki do scen

## Struktura projektu

```text
city-of-mist/
├── index.html           # Strona startowa dla GitHub Pages
├── module.json          # Manifest modułu FoundryVTT
├── README.md            # Dokumentacja projektu
├── scripts/             # Skrypty JavaScript i automatyzacje
│   └── main.js
├── styles/              # Arkusze stylów CSS
│   └── custom-noir.css
├── lang/                # Tłumaczenia systemu
│   └── pl.json
├── assets/              # Grafiki, ikony, audio i inne zasoby
└── ...
```

## Cel projektu

Repozytorium służy jako własny hub zasobów i dodatków do kampanii. Można tu dodawać:

- niestandardowe style i motywy graficzne
- skrypty wspierające rozgrywkę
- tłumaczenia i poprawki tekstów
- dodatkowe elementy świata gry
- personalizację interfejsu dla sesji w klimacie noir

## Rozpoczęcie pracy

1. Sklonuj repozytorium.
2. Zaktualizuj `module.json` zgodnie z nazwą i potrzebami swojej kampanii.
3. Dodaj lub zmodyfikuj pliki w katalogach `scripts`, `styles`, `lang` i `assets`.
4. W przypadku publikacji przez GitHub Pages upewnij się, że ścieżki do zasobów są poprawne.
5. Uruchom projekt w FoundryVTT i testuj integrację.

## Uwagi

Ten projekt jest przeznaczony do rozbudowy i personalizacji. Może być używany zarówno jako baza do własnej kampanii, jak i jako szablon dla podobnych projektów opartych na klimacie noir i śledztwie.
